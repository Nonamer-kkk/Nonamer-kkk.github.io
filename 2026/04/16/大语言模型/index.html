大语言模型

这一章的内容还是比较少的，也比较好理解一点，主要是在上一章预训练语言模型的基础上，进一步介绍了大预言模型及其训练方法。

1. 什么是大语言模型

LLM，即 Large Language Model，中文名为大语⾔模型或⼤型语⾔模型，是⼀种相较传统语⾔模型参数量更多、在更⼤规模语料上进行预训练的语⾔模型。
大语言模型的参数量非常巨大，往往在几十亿到千亿规模之间，远远超过了传统的预训练语言模型。同时，由量变引起的质变使得大语言模型获得了涌现能力，，即在⼀系列复杂任务上表现出远超传统预训练模型（如 BERT、T5）的能⼒与潜⼒。一般而言，只要一个模型具有了涌现能力，就可以被称为大语言模型。

涌现能力

区分 LLM 与传统 PLM 最显著的特征即是 LLM 具备涌现能⼒。涌现能⼒是指同样的模型架构与预训练任务下，某些能⼒在⼩型模型中不明显，但在⼤型模型中特别突出。涌现能⼒是⽬前业界和学界对 LLM 保持较⾼的热情和关注的核⼼所在，即虽然 LLM ⽬前的能⼒、所能解决的任务与⼈类最终所期待的通⽤⼈⼯智能还存在不⼩的差距，但在涌现能⼒的作⽤下，我们相信随着研究的不断深⼊、⾼质量数据的不断涌现和更⾼效的模型架构及训练框架的出现，LLM 终能具备通⽤⼈⼯智能所需要具备的能⼒，从⽽给⼈类⽣活带来质变。

上下文学习

上下⽂学习是指允许语⾔模型在提供⾃然语⾔指令或多个任务示例的情况下，通过理解上下⽂并⽣成相应输出的⽅式来执⾏任务，⽽⽆需额外的训练或参数更新。通过使⽤具备上下⽂学习能⼒的 LLM，⼀般范式开始向 Prompt Engineering 也就是调整 Prompt 来激发 LLM 的能⼒转变。例如，⽬前绝⼤部分 NLP 任务，通过调整 Prompt 或提供 1~5 个⾃然语⾔示例，就可以令 GPT-4 达到超过传统 PLM 微调的效果。

指令遵循

通过使⽤⾃然语⾔描述的多任务数据进⾏微调，也就是所谓的指令微调。
指令遵循能⼒意味我们不再需要每⼀件事都先教模型，然后它才能去做。我们只需要在指令微调阶段混合多种指令来训练其泛化能⼒，LLM 就可以处理⼈类绝⼤部分指令，即可以灵活地解决⽤户遇到的问题。

逐步推理

LLM 通过采⽤思维链（Chain-of-Thought，CoT）推理策略，可以利⽤包含中间推理步骤的提示机制来解决这些任务，从⽽得出最终答案。据推测，这种能⼒可能是通过对代码的训练获得的。逐步推理能⼒意味着 LLM 可以处理复杂逻辑任务，也就是说可以解决⽇常⽣活中需要逻辑判断的绝⼤部分问题，从⽽向“可靠的”智能助理迈出了坚实的⼀步。

多语言支持

LLM 由于需要使⽤到海量的语料进⾏预训练，训练语料往往本身就是多语⾔的，因此 LLM 天⽣即具有多语⾔、跨语⾔能⼒，只不过随着训练语料和指令微调的差异，在不同语⾔上的能⼒有所差异。由于英⽂⾼质量语料⽬前仍是占据⼤部分，以 GPT-4 为代表的绝⼤部分模型在英⽂上具有显著超越中⽂的能⼒。

长文本处理

由于能够处理多⻓的上下⽂⽂本，在⼀定程度上决定了模型的部分能⼒上限，LLM 往往⽐传统 PLM 更看重⻓⽂本处理能⼒。相对于以 512 token 为惯例的传统 PLM（如 BERT、T5等模型的最⼤上下⽂⻓度均为 512），LLM 在拓宽最⼤上下⽂⻓度⽅⾯可谓妙计频出。由于在海量分布式训练集群上进⾏训练，LLM 往往在训练时就⽀持 4k、8k 甚⾄ 32k 的上下⽂⻓度。

拓展多模态

LLM 的强⼤能⼒也为其带来了跨模态的强⼤表现。随着 LLM 的不断改进，通过为 LLM 增加额外的参数来进⾏图像表示，从⽽利⽤ LLM 的强⼤能⼒打造⽀持⽂字、图像双模态的模型，已经是⼀个成功的⽅法。通过引⼊ Adapter 层和图像编码器，并针对性地在图⽂数据上进⾏有监督微调，模型能够具备不错的图⽂问答甚⾄⽣成能⼒。在未来，如何对⻬⽂本与图像的表示，从⽽打造更强⼤的模态⼤模型，将 LLM 的能⼒辐射到更多模态，是⼀个重要的研究⽅向。

幻觉

幻觉，是指 LLM 根据 Prompt 杜撰⽣成虚假、错误信息的表现。例如，当我们要求 LLM ⽣成⼀篇学术论⽂及其参考⽂献列表时，其往往会捏造众多看似“⼀本正经”实则完全不存在的论⽂和研究。幻觉问题是 LLM 的固有缺陷，也是⽬前 LLM 研究及应⽤的巨⼤挑战。尤其是在医学、⾦融学等⾮常强调精准、正确的领域，幻觉的存在可能造成⾮常严重的后果。⽬前也有很多研究提供了削弱幻觉的⼀些⽅法，如 Prompt ⾥进⾏限制、通过 RAG（检索增强⽣成）来指导⽣成等，但都还只能⼀定程度减弱幻觉⽽⽆法彻底根除。

2. 如何训练大语言模型

大语言模型的主要分为三个阶段：Pretrain、SFT、RLHF。

Pretrain

LLM的预训练阶段与传统模型十分相似，都是使用CLM，通过前面的文本来进行预测下一个Token，不过LLM的预训练阶段使用的预训练语料规模更大，以此来获得大量的参数。
如此庞⼤的模型参数和预训练数据，使得预训练⼀个 LLM 所需要的算⼒资源极其庞⼤。事实上，哪怕是预训练⼀个 1B 的⼤模型，也⾄少需要多卡分布式 GPU 集群，通过分布式框架对模型参数、训练的中间参数和训练数据进⾏切分，才能通过以天为单位的⻓时间训练来完成。
正因如此，LLM采用分布式框架，⽬前，主流的分布式训练框架包括 Deepspeed、Megatron-LM、ColossalAI 等，其中，Deepspeed 使⽤⾯最⼴。Deepspeed 的核⼼策略是 ZeRO 和 CPU-offload。
通过分布式框架可以同时使用多张GPU进行训练，⽽且可以将模型参数和训练数据切分到不同的GPU上，进⾏⼀步切分训练，⽽⽆需将所有参数都加载到⼀个GPU上，大大提升了训练的效率。

SFT

Pretrain阶段相当于让LLM学习了大量的知识，而SFT阶段就是想让LLM学会如何使用以习得的知识来回答用户的问题。

RLHF

STF之后，LLM已经学习到了利用知识解答问题的能力，但是想要让LLM生成符合人类价值观的答案，就还需要PLHF阶段的训练。RLHF阶段就好像一个老师批改学生的作业并给他打分，学生收到老师的反馈后就会调整自己的作业来接近老师的要求，LLM就是那个学生。
RLHF分为两个步骤：RM和PPO

RM

RM阶段比较好理解，就是⽤于拟合⼈类偏好，来给 LLM 做出反馈的。在强化学习的训练中，对于 LLM 的每⼀个回复，RM 会进⾏打分，这个打分反映了⽣成回复符合⼈类偏好的程度。然后 LLM 会根据强化学习的原理，基于 RM 的打分来进⾏优化训练。所以，RM 本质上是⼀个⽂本分类模型，对于⼀个⽂本输出⼀个标量奖励，和⽂本分类任务中的隐藏层输出⾮常类似。在具体实现上，RM 也往往就是传统的 LLM 架构（或 BERT 架构）加上⼀层分类层，和⽤于⽂本分类的 LLM 架构完全⼀致，只不过使⽤隐藏层输出⽽不是最后的分类输出⽽已。

PPO

PPO阶段就比较复杂了，具体的步骤如下：

  1. 从 SFT 之后的 LLM 初始化两个模型分别作为 Actor Model 和 Ref Model；从训练的 RM 初始化两个模型分别作为 Reward Model 和 Critic Model
  2. 输⼊⼀个 Prompt，Actor Model 和 Ref Model 分别就 Prompt ⽣成回复
  3. Actor Response 和 Ref Response 计算 KL 散度
  4. Actor Response 分别输⼊到 Reward Model 和 Critic Model 进⾏打分，其中，Reward Model 输出的是回复对应的标量奖励，Critic Model 还会输出累加奖励（即从i位置到最后的累积奖励）
  5. 计算的 KL 散度、两个模型的打分均输⼊到奖励函数中，计算奖励
  6. 根据奖励函数分别计算出的 actor loss 和 critic loss，更新 Actor Model 的参数和 Critic Model 的参数；注意，Actor Model 和 Critic Model 的参数更新⽅法是不同的
    这一块的公式和原理比较复杂，可以看Happy-llm的这一张内容了解。
    其中 Ref Model 和 Reward Model的参数是不更新的，这是是为了限制模型的更新不要过于偏离原模型以⾄于丢失了 Pretrain 和 SFT 赋予的能⼒。
    由于PPO需要消耗大量的训练资源，有人提出了DPO，但这并非主流，这里就不再赘述了。

这一章主要就是一些概念东西，理解好LLM和预训练语言模型的区别以及LLM是怎样训练的，为后面进入搭建LLM的实践打好基础。
